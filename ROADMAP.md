# Development priorities / 开发路线

The current implementation includes one typed generator, checked runtime error
boundaries, isolated builds, classes/callbacks, and Node-driven MoonBit async.
Priorities are correctness and diagnostics, defined API contracts, distribution
validation, tested platform expansion, and measured performance improvements.

当前实现已包含统一类型生成器、运行时错误边界、隔离构建、class/callback 和由 Node
驱动的 MoonBit async。后续依次推进正确性与诊断、明确的 API 契约、分发验证、经过
测试的平台扩展，以及基于测量的性能优化。
